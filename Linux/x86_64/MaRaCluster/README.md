# MaRaCluster 1.04.1

`maracluster` is MaRaCluster 1.04.1 (statisticalbiotechnology/maracluster
rel-1-04-1, commit c122929), built by OpenMS from MaRaCluster's source with zlib
1.3.2 in place of the zlib 1.2.3 that ProteoWizard bundles, which has known
vulnerabilities. Otherwise it is built as MaRaCluster's own release binaries
are, with its builder scripts and the ProteoWizard revision its release build
used (ProteoWizard/pwiz 9ba7317); the recipe is in
https://github.com/OpenMS/THIRDPARTY/tree/master/recipes.
